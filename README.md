# weekly-leetcode

**One LeetCode problem. Every week. In C.**

This is my deliberate practice log — a public record of my journey solving
LeetCode problems, one per week, in plain C.

## Why C?

Because C gives you nothing for free. No built-in hash maps, no string
helpers, no abstractions to hide behind. Solving a "remove duplicates from a
sorted list" problem in C means actually managing pointers and memory —
which is exactly the understanding I want to build, not just the green
checkmark.

- One problem per week, minimum — no binge-solving to fake progress
